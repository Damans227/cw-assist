GitHub repos

The GitHub tab lets you draft an issue from a ticket and open it against one of these repos. Name is free text; repo is owner/name or a github.com URL. The token is a personal access token with issue-write permission on the repos you list.

Tool ids activate tools in chats opened from the side panel — a chat opened from a URL does not inherit the ones you have switched on in Open WebUI. Find them in Open WebUI under Workspace → Tools; comma-separate several.

Self-signed certificate? Open the server URL in a tab once and accept it, otherwise Chrome blocks the request before it leaves.
